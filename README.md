# 📌 Descripción del proyecto

**Library API - Backend** es una API REST desarrollada con **Node.js y Express** para la gestión de libros.

El sistema permite administrar registros mediante operaciones CRUD:

- Crear libros.
- Consultar libros registrados.
- Actualizar información.
- Eliminar registros.

La API utiliza **PostgreSQL** como sistema gestor de base de datos y está preparada para ejecutarse mediante contenedores Docker, facilitando su instalación y despliegue.

Este backend forma parte del proyecto completo **Library API**, integrado con un frontend desarrollado en React.
